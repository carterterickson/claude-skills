# Campaign Bible — Schema & Template

The Campaign Bible is the persistent continuity document for the campaign. It's a Word doc the DM keeps and re-uploads each time they plan a session. Use this schema when building one from scratch, filling gaps in an informal/partial one the user provides, or updating one after a planning session.

Keep entries terse — this is a working reference, not prose. Bullet points and short fields, not paragraphs. The goal is that the DM (or Claude, next session) can scan it in under 2 minutes and know exactly where things stand.

## Sections

### 1. Campaign Overview
- World/campaign name
- Core tone/themes (e.g., "political intrigue with a looming cosmic threat," "gritty survival with dark humor")
- Current story arc / overarching goal
- Current in-world date/location of the party

### 2. The Party
For each of the 6 PCs:
- Name, class/subclass, level
- Core motivation/goal (what they personally want out of the campaign)
- A notable trait, quirk, or unresolved personal thread
- Key relationships (to other PCs, or to NPCs/factions)

### 3. Session History Log
Reverse chronological. One entry per session:
- Session # and date (or "planned — not yet run")
- One-paragraph summary of what happened
- Key decisions/consequences that matter going forward
- Cliffhanger/ending state

### 4. Active Plot Threads
For each ongoing thread:
- Thread name
- Status (dormant / active / escalating / nearing resolution)
- Related NPCs/factions
- What the players know vs. what's still hidden
- Suggested next beat (if there's an obvious one)

Mark resolved threads as **Resolved** rather than deleting them — they're good callback material later.

### 5. NPC Roster
For each significant NPC:
- Name, role/occupation, location
- One-line personality/voice hook (useful for improvising dialogue)
- Relationship/standing with the party
- Current status (alive/dead/missing/imprisoned/etc.) and last-known whereabouts
- Secrets or agenda not yet revealed to players (DM-only)

### 6. Factions
For each faction:
- Name, goals, general disposition
- Standing with the party (hostile / wary / neutral / friendly / allied), and why
- Key members (cross-reference NPC roster)
- Current activity/agenda

### 7. World & Lore Notes
- Key locations visited or referenced (short description each)
- Established world facts/history the players know
- Homebrew rules, deities, factions, or mechanics unique to this setting

### 8. Loose Ends & Callback Opportunities
A running list of small unresolved details, promises, foreshadowing, or unanswered questions — great fodder for "oh, that pays off now" moments. Prune items once used, or mark them Used.

## Update Discipline

When updating after a planning session, don't just append — actually revise. Move resolved threads to Resolved, update NPC status/location if they moved, retire loose ends that got used, and add new ones the just-planned session introduces. Keep the doc from bloating: if the History Log gets long, consider a compressed "story so far" summary at the top and keep full entries only for the last 5-10 sessions.
